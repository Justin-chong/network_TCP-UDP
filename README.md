# NetAssist — TCP/UDP 网络调试助手

基于 **Qt 6 (Widgets + Network)** 与 **C++17** 开发的跨协议网络调试工具，支持 **TCP Client / TCP Server / UDP** 三种工作模式，内置自研 `AA 55` 二进制协议引擎，用于解决嵌入式设备联调、上位机通信开发中的字节流收发、黏包拆帧与数据校验问题。

---

## ✨ 功能特性

| 分类   | 功能             | 说明                                      |
| ---- | -------------- | --------------------------------------- |
| 通信模式 | TCP Client     | 主动连接远端主机，支持连接/断开状态管理                    |
| 通信模式 | TCP Server     | 监听本地端口，支持**多客户端并发接入**，按 clientId 寻址、可广播 |
| 通信模式 | UDP            | 单播 / 广播，`ShareAddress` 端口复用             |
| 数据收发 | ASCII / Hex 双模 | 发送与接收均支持文本与十六进制两种视图独立切换                 |
| 数据收发 | 文件发送           | 选择本地文件整体发送                              |
| 数据收发 | 自动发送           | 自定义周期（ms）循环发送，连接断开自动停止                  |
| 数据收发 | 接收落盘           | 接收数据带时间戳追加写入指定文本文件                      |
| 协议引擎 | AA 55 帧解析      | 流式缓冲处理 TCP **黏包 / 半包**，帧头重同步，累加和校验      |
| 其他   | 本机网卡枚举         | 自动枚举本机所有 IPv4 地址供选择                     |

## 🏗️ 架构设计

项目采用分层解耦结构，UI 层只做信号槽编排，不直接触碰网络；网络模块对上层只暴露业务接口，不泄露裸 socket 指针。

```
┌─────────────────────────────────────────────────────┐
│  UI 层          MainWindow（信号槽编排）            │
│  网络设置 / 接收设置 / 发送设置 / 数据日志           │
├─────────────────────────────────────────────────────┤
│  模型层          SendModel（Text/Hex/File 发送数据） │
│                  ProtocalParser（AA55 协议引擎）     │
│                  QTimer（自动发送周期触发）          │
├─────────────────────────────────────────────────────┤
│  网络封装层      TcpConnection  ──  QTcpSocket      │
│                  TcpServerHost  ──  QTcpServer     │
│                  UdpSocket      ──  QUdpSocket     │
└─────────────────────────────────────────────────────┘
```

- **事件驱动**：全部收发由 Qt 事件循环的信号槽驱动（`readyRead` 到达即回调），无轮询、无阻塞等待，单线程内无锁运行。
- **协议引擎独立成模块**：`ProtocalParser` 与具体传输方式无关，TCP / UDP 复用同一套拆帧逻辑。
- **TCP Server 封装**：内部维护 `ClientInfo { socket, id, address }` 列表，对外通过 `clientId` 通信；客户端断开时 `sender()` 定位并 `deleteLater()` 回收。

## 🚀 快速开始

### 环境要求

- Qt **6.x**（Widgets + Network 模块），已在 Qt 6.10.2 / MinGW 64bit 下验证
- 支持 C++17 的编译器（MinGW / MSVC）
- Windows（`QTcpServer` / `QUdpSocket` 为跨平台 API，理论上可直接移植 Linux/macOS）

### 编译运行

方式一：命令行（以 MinGW 为例）

```bash
qmake NetAssist_TCPUDP.pro
mingw32-make
```

方式二：Qt Creator 直接打开 `NetAssist_TCPUDP.pro`，点击运行。

## 📡 使用说明

### TCP Client

1. 协议类型选择 `TCP Client`；
2. 填写远程主机地址与端口，点击「连接」；
3. 在发送区输入数据（ASCII 或勾选 Hex 输入十六进制），点击「发送」；
4. 勾选「自动发送」并填写周期（ms）可循环发送。

### TCP Server

1. 协议类型选择 `TCP Server`；
2. 选择本地监听地址（自动枚举本机 IPv4）与端口，点击「开始」；
3. 客户端接入后出现在「客户端列表」，所有接收数据在日志区按 `Client ID` 区分；
4. 发送内容默认**广播给全部已连接客户端**。

### UDP

1. 协议类型选择 `UDP`，填写本地绑定端口，点击「绑定」；
2. 在远程主机地址/端口栏填写目标，按数据报发送。

## 🔌 自定义协议（AA 55 帧格式）

勾选「启用 AA 55 协议」后，收发将按下列二进制帧格式校验与解析：

```
┌────────┬──────┬──────┬─────────┬───────────┐
│ 帧头   │ 长度 │ 类型 │ 数据    │ 校验和    │
│ 2 字节 │ 1 字节│ 1 字节│ N 字节  │ 1 字节    │
│ AA 55 │ LEN  │ TYPE │ DATA... │ CHECKSUM  │
└────────┴──────┴──────┴─────────┴───────────┘
```

| 字段  | 规则                                                     |
| --- | ------------------------------------------------------ |
| 帧头  | 固定 `0xAA 0x55`，用于在字节流中定位帧起始                            |
| 长度  | `LEN = 类型(1) + 数据(N)`，即类型与数据的总字节数                      |
| 类型  | 命令类型：`0x00` 心跳、`0x01` 数据帧、`0x02` 应答帧、`0xFF` 错误帧，其余为自定义 |
| 校验和 | `(帧头 + 长度 + 类型 + 数据) 逐字节累加 & 0xFF`                     |

### 解析规则

- **半包**：缓冲区长度不足完整帧时等待后续数据到达再解析；
- **黏包**：缓冲区中凑齐一帧后立即取出，剩余数据留在缓冲继续解析（单次 `readyRead` 可拆出多帧）；
- **帧头重同步**：缓冲前存在脏数据时，扫描定位下一个 `AA 55` 重新对齐；
- **校验失败**：整帧丢弃，从缓冲中重新搜索帧头。

### 帧示例（数据内容为 `"Hi"`）

```
AA 55 03 01 48 69 B4
└┬┘ └┬┘ └┬┘ └──┬──┘ └┬┘
 │   │   │     │     └─ 校验和 = (AA+55+03+01+48+69) & 0xFF = 0xB4
 │   │   │     └─────── 数据 = "Hi"（0x48 0x69）
 │   │   └───────────── 类型 = 0x01（数据帧）
 │   └───────────────── 长度 = 3（类型1 + 数据2）
 └───────────────────── 帧头
```

校验和算法可运行 `python test_checksum.py` 交叉验证。

## ⚠️ 已知限制与演进方向

当前定位为**单机调试工具**，已知边界如下：

| 限制   | 现状                   | 演进方向                             |
| ---- | -------------------- | -------------------------------- |
| 文件发送 | 一次性读入内存（`readAll()`） | 按块分读 + `bytesWritten` 背压流控，支持大文件 |
| 运行模型 | 全部逻辑在 GUI 单线程        | 协议解析下沉独立工作线程，避免大数据量阻塞界面          |
| 日志区  | 接收文本无上限追加            | 增加最大行数裁剪，限制长时间运行的内存增长            |
| 组播   | UDP 组播接口已预留但暂未启用     | 完成组播收发与 `joinMulticastGroup` 封装  |
